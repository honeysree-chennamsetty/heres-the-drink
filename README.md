# Here's The Drink 🍺

An Android application for discovering and checking the
availability of drink products.

## 🚀 Features

- User Registration & Login
- Drink Product Categories
- Product Search
- Product Details
- Availability Checking
- User Profile
- Firebase Authentication
- Firebase Realtime Database
- Push Notifications

## 🛠️ Technologies

- Java
- Android
- Firebase Authentication
- Firebase Realtime Database
- Firebase Cloud Messaging
- Gradle
- Picasso
- Gson

## ⚙️ Setup

1. Clone the repository
2. Open the project in Android Studio
3. Configure Firebase
4. Add `google-services.json`
5. Sync Gradle
6. Build and run the application
